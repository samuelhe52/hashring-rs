## 打开和演示

在 Windows PowerShell 执行这一行，终端保持开启。

```powershell
wsl -d Debian -- bash -lc 'cd "/mnt/d/数据结构课程/实验7/项目/hashring-rs/dashboard" && npm start'
```

打开 `http://localhost:4173/?run=my-latency-20261028-013354`。这台机器已有 Node 24、依赖、生产构建和 release 实验二进制。

1. **概览**。可以说「这里读取 Rust 实验留下的文件。这个结果是三节点、RF 3，左边是实际速率和 GET p99，右边点目标阶段可以换读数。」
2. **案例分析**。可说「这次运行从 500 到 1,000 ops/s，实测速率跟上了目标。两档的 GET p99 分别是 732 和 660 微秒。这是这次记录的差值。可以下载带来源的图。」点击 PNG 或 SVG，或者点「实际速率」展示条形对比。
3. **历史回放**。点击「播放」并调到 5×。可说「左边按原时间推进曲线或哈希环，右边能核对事件和窗口读数。」到某条事件可以暂停，点右侧目录找原始字段。
4. **运行实验**。从表单或 YAML 预览命令、下载 `.sh`。确认现场可以开跑时再点「启动实验」，实时页能看曲线、事件和拓扑，也可以停止并保留已写入的文件。只演示历史时用上面三步。
