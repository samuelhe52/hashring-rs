## 只看原来的样子

直接打开两张 PNG。原版默认选中 `my-latency-20261028-013354`，包含结果概览、配置、原文、日志与事件时间线。

## 临时运行原版，和新版对照

1. 将两个 ZIP 解压到一个新的临时文件夹，例如 `D:/dashboard-original-preview/`。里面应并列有 `dashboard/` 和 `results/`。
2. 在 WSL Debian 中进入这个临时目录的 dashboard。
3. 执行 `node server/index.mjs`。原版已带 dist，浏览构建后的页面不需要安装前端依赖。
4. 浏览器打开 `http://localhost:4173`。若新版正占用端口，可用 `PORT=4174 node server/index.mjs`，打开 4174。
5. 按 Ctrl+C 停止。

这只是对照预览；项目工作目录仍为 `D:/数据结构课程/实验7/项目/hashring-rs`。

## 要恢复到原仓库时

先保留新版 dashboard 的另一份备份，停止网页服务，再将 `dashboard-original.zip` 中的 dashboard 内容覆盖回原仓库的 dashboard。ZIP 不含新版后来新增的文件，完全回退时还需对照 ZIP 目录处理这些新增文件；不要直接删除整个项目或 results。

当前结果数据无需恢复。只有确定原始 results 被改坏时，才考虑使用结果备份。恢复操作应由你明确决定，本次只创建备份。

备份没有提交或推送到 GitHub。
