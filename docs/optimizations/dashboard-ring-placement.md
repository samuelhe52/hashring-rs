# Dashboard 复用二分查找得到的哈希环位置

区间归属和拓扑差异都需要从 token 的顺时针位置开始寻找不同的物理节点。原实现用二分查找找到该位置，再对整个位置数组执行 `indexOf`。现在直接复用二分查找返回的索引，保留相同 token 的顺序和副本遍历规则。移除线性搜索后，单次起点定位从 O(n) 降为 O(log n)，寻找不同副本所需的遍历仍取决于节点排列和 RF。

在 Apple M1 Pro 上用 Node.js 26.13.0 对同一份合成拓扑各运行一次，共 32 个节点、131,072 个均匀分布的位置，RF 为 3。解码从 1,916 ms 降至 108 ms，同一拓扑的区间比较从 3,804 ms 降至 131 ms。比较输出逐项一致。计时覆盖数据处理，浏览器渲染耗时另计。
