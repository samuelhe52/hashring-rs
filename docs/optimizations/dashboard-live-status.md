# Dashboard 实时轮询使用副本状态摘要

实时面板使用拓扑版本、区间总数、副本不足的区间数和节点状态。Dashboard 现在用一次 CLI 调用获取这些字段，并由 CLI 在序列化前汇总区间。协调器仍返回完整的副本状态 RPC，供 CLI 使用同一份区间状态计算摘要。普通 `replica-status` 命令保留逐区间明细。

使用配置了八个成员、每成员 4,096 个虚拟位置且 RF 为 3 的本地协调器验证。实时 API 返回 692 字节，完整 `replica-status` 标准输出为 44,920,303 字节，超过原 8 MiB 子进程输出上限。两次读取的区间总数和副本不足区间数均为 32,768。协调器未连接运行中的数据节点，这次检查覆盖了大拓扑的状态读取和传输。
